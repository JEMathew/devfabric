# Personas and Jobs to Be Done

One invoice reminder moves between six decision owners. Each needs evidence from the previous step before taking responsibility for the next.

| Persona | Job to be done | What makes the next step possible |
| --- | --- | --- |
| Developer | Find an owned contract and get a sandbox without coordinating several disconnected requests. | A service, accountable team, contract and request linked to a ready environment. |
| Platform administrator | Fulfil eligible requests and return a recoverable decision when a request fails. | A policy result, a decision owner and a provisioning record. |
| API owner | Make an operation usable by an agent and identify changes that require a new review. | Required evidence, assessment and publication bound to the same revision. |
| Agent operator | Choose a tool for the task and understand its scope before running it. | A registered agent, sandbox target, runtime decision and invocation receipt. |
| Security reviewer | Decide whether the contract or task evidence justifies approval. | The revision or invoice-specific result under review and an attributable disposition. |
| Platform product manager | Decide whether a pilot is ready to expand. | Completed tasks, review load, denials and recovery evidence alongside explicit cost assumptions. |
